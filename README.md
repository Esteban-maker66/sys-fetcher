# sys-fetcher

## Description

A small, zero-dependency Node.js CLI tool to fetch and summarize GitHub repositories using the GitHub API. Designed to be simple, readable, and easy to use from scripts or the terminal.

## Features

- Query a GitHub user's public repositories
- Provide a concise summary or report for offline use
- Minimal setup — runs with Node.js only

## Requirements

- Node.js (LTS recommended)

## Installation

Clone or copy this `cliTool` folder into your project. No install step required if you run the script with Node.js.

## Usage

Run the CLI with a GitHub username:

```
node sys-fetcher.js --user=usernameExample
```

Short options and examples are provided by the script itself (try `--help`).
